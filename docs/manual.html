台股大戶撤退與籌碼風險判讀儀表板 — 操作手冊

整合台灣證交所、期交所、集保中心 TDCC 與券商主力分點，提供量化風險評分、部位控管與 12 檔低估值個股買點評估

一、快速啟動與雙模式使用說明

推薦 模式 1：雙擊捷徑一鍵連線看盤
  1. 雙擊根目錄的 台股籌碼儀表板.lnk（或 start_dashboard.bat）。
  2. 初次使用會自動建置獨立 Python 虛擬環境並安裝 requests。
  3. 伺服器會在 1 秒內開啟瀏覽器（http://127.0.0.1:8765）先顯示快取數據，並於背景自動同步最新官方盤後資料（約 3～5 秒；若逢週五晚間首次抓集保週檔約 20～35 秒），完成後畫面自動刷新。
  4. 保持黑色命令列視窗開啟，即可隨時點擊頁面右上角「一鍵同步最新市場數據」。
免伺服器 模式 2：單檔離線模式
  1. 直接雙擊 src/code_artifact.html 即可在任何瀏覽器離線開啟。
  2. 每次透過 Python 同步完成後，最新盤後數據都會自動回寫內嵌至該 HTML 檔中。
  3. 離線模式仍可自由微調各指標滑桿、試算加減碼金額、存取歷史紀錄；亦可點右上角「同步設定」填入個人 Gemini API Key 作為聯網備援同步。

維度四：技術超跌與量能 Yahoo Finance + 證交所 FMTQIK 大盤日線 KD(9,3,3) 位階、成交金額對 20 日均量比（辨識爆量恐慌殺盤 vs 量縮窒息止穩）。

三、12 檔觀察名單與個股籌碼三件套

進場評估燈號邏輯
  • 右側買進確認 股價站上 5 日與 10 日均線，日 KD 偏多且 2027E 本益比具吸引力。
  • 達左側首波試單價 進入合理價值買進區間或逼近 52 週低點 7.5% 以內，適合小額分批建立底倉。
  • 估值偏低・接近買點 距左側試單上緣在 6.5% 以內，可列入優先盯盤。
  • 補跌修正・暫觀望 單日急跌逾 5.8% 且距 52 週低點仍遠，避免第一天急接。
大戶與主力籌碼三件套
  • 集保中心 TDCC（每週五更新）：追蹤千張大戶、400 張大戶持股比例，以及 10 張以下散戶人數週增減（本機自動保存近 52 週快照於 data/tdcc_weekly_history.json）。
  • 近 4 週大戶趨勢：整合近 20 週 400 張大戶持股序列，快速辨識連續吸籌或撤退。
  • 前 15 大主力與分點：顯示當日前 15 大主力淨買賣超張數，以及最大買超／賣超券商分點名稱。

四、個人資金試算、歷史紀錄與常見問題

資金試算器與歷史追蹤
  • 輸入總投資資金、目標持股與現金比例，系統依據風險分數自動建議本次應加碼或減碼金額。
  • 點擊「儲存今日判讀快照」可將數值存於瀏覽器 localStorage，支援繪製歷史風險趨勢長條圖與 JSON 匯出／匯入備份。
常見問題排除
  • 網頁顯示「單檔離線模式」：代表未開啟本機 Python 伺服器，請雙擊 台股籌碼儀表板.lnk 即可連線自動同步。
  • 週五晚間同步較久：集保 TDCC 原始檔約 2.4 MB，每週首次換週下載需 20～35 秒（超過 45 秒會自動回退舊快取），平日有快取僅需 3～5 秒。
