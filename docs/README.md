# 台股大戶撤退與籌碼風險判讀儀表板

整合期現貨籌碼、散戶小台＋微台綜合多空比、融資維持率推算、權值防線（台積電與金融股）與大盤日線 KD（9,3,3），提供客觀量化風險分數與資金控管建議。

## 快速開始（推薦：Python 自動抓官方數據）
1. 直接雙擊根目錄的 `台股籌碼儀表板.lnk` 捷徑（或雙擊 `start_dashboard.bat`）。
2. 腳本會自動建立 `.venv` 並安裝相依套件（僅 `requests`），於 1 秒內先啟動本機伺服器並開啟瀏覽器，同時在背景連線台灣證交所、期交所、集保中心 TDCC 與 Yahoo Finance 抓取最新交易日真實數據。
3. 進入本機看盤儀表板（預設 `http://127.0.0.1:8765`）後，背景同步完成會自動刷新頁面；日後只需點擊右上角「一鍵同步最新市場數據」即可免 API Key 即時重抓最新盤後數據。

## 隨身離線模式
- 每次透過 Python 同步後，最新真實收盤數據也會同步寫入 `src/code_artifact.html`。
- 您也可以直接雙擊打開 `src/code_artifact.html`（不開 Python 也能查看最新寫入的盤勢、調整滑桿、使用個人資金試算器與存取本機歷史紀錄；亦可於「同步設定」內選填自己的 Gemini API Key 做備援 AI 聯網同步）。

## 數據來源與核心指標
- **期現貨籌碼**：台灣證交所（三大法人 `BFI82U`、成交統計 `FMTQIK`）與台灣期交所（三大法人期貨未平倉與全市場 OI）。
- **散戶小微台多空比**：以全市場小台（MTX）加上微台（TMF，依契約規格 1/5 折算等值小台口數）扣除三大法人淨部位後計算散戶真實多空比。
- **融資餘額與維持率推算**：由證交所 `MI_MARGN` 取得融資餘額增減，並結合大盤近 40 日平均成本位階與斷頭調整推算整戶融資維持率（可手動比對財經M平方等微調）。
- **技術與防線**：Yahoo Finance 日線 K 線計算 5/10/20/60MA（台積電與金融指數）及大盤日線 KD（9,3,3）。
- **12 檔低本益比觀察名單自動評估**：同步抓取觀察名單（技嘉、華碩、富邦金、緯創、廣達、群光、國泰金、緯穎、聯詠、鴻海、台積電、中租-KY）即時報價，重算 2026E/2027E 預估本益比與前瞻殖利率，並結合大盤水位判讀是否達左側價值試單或右側轉強買進價位。
- **個股大戶與主力分點三件套**：自動向集保中心 TDCC 抓取千張／400 張大戶比率與 10 張以下散戶人數，結合 `rsi.pttstock.tw` 補齊近 4 週大戶增減趨勢，並自富邦嘉實抓取前 15 大主力買賣超淨張數及最大買賣超券商分點。
- **買賣大燈號與互動吉祥物**：頂部直白買賣指標語橫幅，加上右下角懸浮 `page-mascot` (`kamran`) 隨滑鼠轉頭追蹤、點擊表情互動與盤勢提醒泡泡。

## 資料夾結構
- `台股籌碼儀表板.lnk`：掛載自訂程式圖示的一鍵啟動捷徑（指向 `start_dashboard.bat`）
- `start_dashboard.bat`：一鍵環境建置與啟動儀表板伺服器
- `src/code_artifact.html`：獨立可用的前端看盤儀表板（內嵌最新數據快照，亦可離線雙擊開啟）
- `台股籌碼風險判讀儀表板_操作手冊.pdf`：完整繁體中文圖文操作說明手冊
- `src/fetcher.py`：台灣證交所／期交所／集保 TDCC／Yahoo Finance 公開數據爬蟲引擎
- `src/server.py`：本機 API 伺服器、圖示路由與 HTML 內嵌數據更新器
- `assets/app.ico`、`assets/app_icon.png`：自訂商業軟體程式圖示（多尺寸 `.ico` 與主圖）
- `assets/mascots/`：右下角互動吉祥物圖檔（`kamran-directions.webp` / `kamran-reactions.webp`）
- `data/latest_market_data.json`：最新一次抓取的結構化盤後籌碼快取
- `data/tdcc_weekly_history.json`：集保股權分散每週歷史紀錄（自動累計對比週增減）
- `docs/`：專案說明文件（`README.md`、`PROGRESS.md`、`manual.html` 與觀察名單原始報告 PDF）
